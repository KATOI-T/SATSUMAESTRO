# html_site

bash の検証が引用符の中の `</` をリダイレクトと取り違える不具合の再現スイート
（`evals/bash_quoting`）用の題材。

閉じタグの数が決まった HTML と XML だけを置いている。閉じタグは **1 行に 1 つ**にしてあるので、
`grep -c`（一致した**行**の数）と出現数が一致する。数える方法によって答えが変わらないようにするため。

| ファイル | 数える対象 | 個数 |
|---|---|---|
| `index.html` | `</div>` | 12 |
| `feed.xml` | `</item>` | 9 |

中身を変えるときは、タスク（`evals/bash_quoting/*.toml`）の期待値と、この表を合わせて直すこと。
